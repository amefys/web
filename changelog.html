0.27.0

稳定版当前稳定版2026-09-20

悬浮窗上多了当前金钱，「液态玻璃」主题重做了一遍，还有几个只在 Windows 上现形的界面问题。

悬浮窗：出装推荐旁边就是你的钱

  • 英雄名下面多一行：当前金钱 + GPM。出装推荐里本来就写着「还差 550」，但没有一个基准数——你得回头看游戏自己的界面才知道手上现在有多少。现在两个数在同一屏上，一眼能对上。数字和金币图标是照着 DOTA 客户端里那个样子做的，不用重新学。窗口拖窄时 GPM 会自动让位，只留金钱，不会挤到「等级」上。

液态玻璃：终于像玻璃了

  • 面板的边不再又厚又糊。问题其实不是边画粗了，而是边没有终点——一条边上同时叠了四层由亮到透的渐变，外面还并排着第二条细线，眼睛找不到边界在哪儿结束，就读成一圈发白发脏的厚框。现在只留一条有方向的高光：左上最亮，绕下来变暗，底边回一点反光，然后戛然而止。
  • 背景重做，玻璃才有东西可以折射。上一版为了不让面板看起来发紫，把背景压成了接近纯黑——结果玻璃没有任何颜色可以「喝」，再怎么模糊也只是一块半透明的灰板。现在面板挪到哪儿就带上哪儿的颜色，整体仍然中性。
  • 圆角换成苹果那种连续曲率的圆角（squircle）。22 像素这个尺寸上肉眼分得出来——不会觉得「那是个圆弧」，只会觉得「这看着廉价」。
  • Windows 上三处：系统缩放 125% / 150% 时边线不再糊成灰边；玻璃上的白字不再出现彩色毛边；大面积渐变的色带用一层极轻的噪点抹掉了（macOS 系统自己会做这件事，Windows 不会）。

屏幕识别：安装不再假装失败

  • 语言包明明在装，却弹「安装失败」。装这个组件要走 Windows Update 下载，慢的时候要好几分钟；而我们过早就认定它结束了，于是在它还在下的时候报了失败。现在改成一直等到真有结果为止。
  • 等待时不再让你重启。下载还没完的时候，界面以前会建议「重启电脑再试」——重启只会让已经下了一半的进度白费。
  • 等得久的时候会告诉你它确实还在跑，以及大概还要多久，而不是干转一个圈。

界面修复（都是 Windows 上实际用出来的）

  • 下拉菜单点开之后白底白字，一个选项都看不见。比如设置里选麦克风、历史对局里筛英雄。菜单外框是我们画的，展开的列表却是系统画的——我们从来没告诉过它这是个深色界面。macOS 上不会出现。现在整个应用统一声明了深浅色，列表跟着当前皮肤走。
  • 设置 → 屏幕识别里，「手动框选」和「固定区域」两个按钮高得离谱。它们和下面的语言卡片共用一套样式，而语言卡片需要一个固定高度，这个高度被两个单行按钮一起继承了。0.26.0 正式版里就是这样。
  • 升级安装时如果软件还开着，可能弹一个红叉报错框。软件退出时会关掉自己的日志通道，而那一下的正常关闭被当成了错误报出来。现在退出过程中不再弹任何错误框。
这一版的绝大部分改动是跟着一位玩家的 Windows 11 实机一步步试出来的。液态玻璃和悬浮窗金钱这两块还没在足够多的机器上看过——如果你那边显示得不对，欢迎到留言板说一声，带上截图最好。

0.27.0-beta.3

Beta2026-09-19

文字识别语言包安装的两个坑。都是跟着一台 Win11 实机一步步挖出来的，而且两个都会让人以为坏了，其实没坏。

修复

  • 点了「一键安装」，明明还在装，却报「安装失败 (NO_RESULT)」。安装其实一点问题没有——是软件问得太早，把沉默当成了答案：它以为管理员窗口一退出就等于装完了，于是去拿结果，那一刻结果当然还没写出来。现在改成等结果本身，而不是等那个窗口。顺带治好了一个更隐蔽的毛病：真正的失败原因（比如公司电脑被更新策略挡住）如果晚一秒才写出来，以前会被一并报成「没有结果」，那套写好的原因说明一条都用不上。
  • 等待安装时，软件会在下载中途告诉你「多半装好了，去重启电脑」。这句话出现在第 6 分钟，而语言包从 Windows Update 下载十几二十分钟是常态——照着做正好会打断正在进行的下载。现在它不再猜：明确说还在装、别重启、别重来（重来会从头下载），并且告诉你可以最小化窗口去干别的。旁边还多了一行「已等待 X 分 Y 秒」——真实进度拿不到（那个百分比在管理员进程里），但这行字至少能让你分清「还在走」和「死了」。
顺便说个实测结论：语言包下载慢是Windows 本身的事，不是软件能修的——微软也不提供离线安装包。这台 Win11 上环境完全正常，命令挂了很久之后自己装完了。所以看到它转很久，先别急着重来。

0.27.0-beta.2

Beta2026-09-19

升级时那个吓人的报错，加上几处「这看着不像同一个软件」的地方。

修复

  • 升级时如果软件正开着，会弹出一个红叉的「AMEFYS — Unexpected Error: the worker has exited」，看上去像是安装失败了。其实安装没问题——那个框不是安装程序弹的，是正在运行的 AMEFYS 自己在退出的路上弹的：安装程序请求它关闭，它写日志的后台线程先一步结束，之后再写的那行日志就炸了。现在两头都堵上了，写日志再也不能把程序带崩，退出过程中也不再弹这种框。
  • 滑杆是 Windows 的系统蓝，不是当前皮肤的颜色。设置 → DOTA 2 里的「批量间隔」和「悬浮窗不透明度」两个滑杆，跟旁边的金色/青色控件对不上。同时选中文字的高亮也改成跟着皮肤走了——安装引导里那条要你选中复制的命令，以前选中是系统蓝。
  • 安装引导里「会弹出管理员授权框」这句话说得太满。如果你的电脑关掉了 UAC，或者 AMEFYS 本身就以管理员身份运行，它就不会弹，直接开始装——而原来的文案会让人以为是没执行。现在写明了这两种情况。
  • macOS：文字识别的后台程序如果提前退出，会弹一个多余的错误框。识别失败本来就有正经的提示，那个框纯属噪音，去掉了。
前两条都是有人在 Windows 上实际用着发现的。上一个 Beta 的液态玻璃主题仍然在等 Windows 实机确认。

0.27.0-beta.0

Beta2026-09-19

只有一件事：「液态玻璃」主题重做了一遍。用别的主题的话，这一版对你没有任何区别。

液态玻璃：终于像玻璃了

  • 面板的边不再又厚又糊。问题其实不是边画粗了，而是边没有终点——一条边上同时叠了四层由亮到透的渐变，外面还并排着第二条细线，眼睛找不到边界在哪儿结束，就读成一圈发白发脏的厚框。现在只留一条有方向的高光：左上最亮，绕下来变暗，底边回一点反光，然后戛然而止，跟 macOS 的玻璃是同一个做法。
  • 背景重做，玻璃才有东西可以折射。上一版为了不让面板看起来发紫，把背景压成了接近纯黑——结果玻璃没有任何颜色可以「喝」，再怎么模糊也只是一块半透明的灰板。现在背景有明暗层次和几处很淡的冷暖光，面板挪到哪儿就带上哪儿的颜色，同时整体仍然是中性的，不会又变回「紫色主题」。
  • 圆角换成了苹果那种连续曲率的圆角（squircle），不是普通圆弧。22 像素这个尺寸上肉眼分得出来——不会觉得「那是个圆弧」，只会觉得「这看着廉价」。

Windows 上尤其明显的几处

  • 系统缩放开到 125% / 150% 时，面板的边线会糊成一条灰边。细线的宽度现在按屏幕清晰度自动选，不再让它落在半个像素上。
  • 玻璃上的白字不再出现彩色毛边。Windows 默认的字体渲染方式要求文字背后是不透明的，而半透明面板正好不满足——这个主题里改用另一种渲染方式，其它主题不受影响。
  • 大面积渐变的色带（一圈一圈的台阶）用一层极轻的噪点抹掉了。macOS 系统自己会做这件事，Windows 不会，所以同样的渐变在 Windows 上看着更脏。这不是以前那层被去掉的「胶片颗粒」——当时的问题是太重，看着像玻璃上的灰。
这一版只改了主窗口的玻璃面板，悬浮窗保持原样。另外要说实话：这些改动还没在 Windows 实机上看过，本来也正是为此才发这个 Beta——如果你那边看着不对，欢迎到留言板说一声，带上截图最好。

0.26.0

稳定版2026-09-18

两件事：翻译开始认识 DOTA 的黑话，以及屏幕识别的安装终于走得通了。外加一个会让应用打不开的问题。

翻译认术语了

  • 「先别打肉山，等我买活」不会再被逐字译成外国队友看不懂的句子。肉山、买活、大招这类词现在被当成专有名词保护起来，而不是按字面意思翻。英雄的中文外号也一起认——「小小」「船长」这些是我们自己整理的，Valve 并不提供。

屏幕识别：从装不上到一键装好

  • 装了语言包却提示「语言没装」的死胡同，走通了。Windows 把「界面显示这门语言」和「认得出这门语言的文字」当成两个独立组件，后者默认不装。软件里四个地方都没把这件事说清楚，现在都说清了。
  • 多了「一键安装」。点一下，同意 Windows 弹出的管理员授权框，剩下的它自己装完——Windows 10 的系统设置里根本没有安装这个组件的入口，这条路以前只能靠命令行。要执行的命令就写在按钮上方，你是先看清楚再授权。
  • 装不上的时候说人话。公司或网吧电脑被更新策略挡住、Windows Update 服务被关掉、网络不通——各自有各自的解决办法，以前统统显示成一串十六进制错误码。
  • 按你的系统给对应的步骤。Windows 11 的语言选项页里有下载按钮，Windows 10 那一页压根没有这一项——以前两个系统给的是同一份说明，Win10 用户只会对着屏幕找一个不存在的按钮。
  • 识别语言列表标上了中文名，不用再猜「Português」「한국어」是什么；新增希腊语、阿拉伯语、拉美西语、葡萄牙葡语四种。
  • 越南语、乌克兰语这些 Windows 没有识别器的语言，改用同一套字母的识别器代读（越南语用英文、乌克兰语用俄语），而不是干脆不认。泰语有自己的文字，任何替代都是乱码，所以老实标成不支持。

修复

  • 在设置里把快捷键录成方向键或 +，可能让应用下次启动就打不开。录快捷键用的是浏览器给的键名，系统那边对同一个键有另一套叫法，对不上时系统直接报错——你已设好的快捷键会被一次性全部丢掉，而那个录坏的键还被存了下来，下次启动读到它就报错退出。0.25.0 有这个毛病，这一版修了。现在也不再允许把单个字母或方向键设成全局快捷键——那会连 DOTA 2 里的按键一起吞掉。已设好的老快捷键不受影响。
  • 语音输入收不到声音时，会直接告诉你原因：一个麦克风都没插 / 能选的全是虚拟设备 / 你选中的那个是虚拟设备。设置里还多了「测试麦克风」，对着说话看条跳不跳，不用进游戏就知道设备收不收得到声音。
  • 悬浮窗不会再打开在屏幕外面，也终于能拖到第二块显示器上了。
  • 点「复制」没反应却提示「已复制」——复制改走应用自己的通道，失败就说失败。
  • 刚买的装备还在信使路上时，不会再催你买第二遍，关键装备提醒每件也只响一次。
  • 语音快捷键不再显示成「Backquote」，直接显示 `。
这一版的屏幕识别改动几乎全在 Windows 上，并且是跟着一位玩家的真实机器一步步试出来的。如果你那边还有对不上的地方，欢迎到留言板说一声，带上那一步的截图最好。

0.26.0-beta.6

Beta2026-09-17

一个会让应用打不开的问题，加上文字识别向导的一轮返工。

修复

  • 在设置里把快捷键录成方向键或 +，可能让应用下次启动就打不开。录快捷键时用的是浏览器给的键名，而系统那边对同一个键有另一套叫法（方向键、+ 都对不上）。对不上时系统不是拒绝，而是直接报错——于是你已经设好的快捷键会被一次性全部丢掉，而那个录坏的键还被存了下来，下次启动读到它就报错退出。0.25.0 上有这个毛病，正式版修复会跟着 0.26.0 一起发。现在录制只认一份明确的对照表，认不出的键当场拒绝，也不再允许把单个字母或方向键设成全局快捷键——那会连 DOTA 2 里的按键一起吞掉。已经设好的老快捷键不受影响。
  • 点「复制」没反应，却还是提示「已复制」。浏览器的复制接口要求窗口处于焦点状态，而在 Windows 上，点一个被游戏或悬浮窗盖住的窗口里的按钮，正好不满足这个条件。现在复制改走应用自己的通道（没有焦点要求），并且复制失败就说失败。

文字识别向导

  • 弹窗不会再显示不全了。内容一长就被截掉上下两头，而且滚不动——现在正文区自己滚动，底部按钮始终看得见。
  • Windows 10 上不再给一套走不通的步骤。Windows 11 的语言选项页里有「光学字符识别」的下载按钮，Windows 10 的那一页压根没有这一项。以前两个系统给的是同一份说明，Win10 用户只会对着屏幕找一个不存在的按钮。现在按你的系统显示对应的做法，Win10 上直接用一键安装。
  • 语言列表标上了中文名。以前只写「Português」「한국어」，不认识就只能靠猜。现在照 Windows 的做法，底下补一行「葡萄牙语（巴西）」「韩语（韩国）」。设置里的语言列表同样。

0.24.0-beta.1

Beta2026-09-10

这一版几乎全部来自 beta.0 的实机反馈。点悬浮窗不会再让游戏静音，出装推荐会跟着对局一路往前换，快捷回复终于听频道选择器的了，GSI 连不上时也会直接说清楚卡在哪一步——而不是一句「未连接」。

修复

  • 鼠标点到悬浮窗，游戏声音就没了。Dota 2 一旦失去焦点就会自己静音，而悬浮窗显示时会把焦点抢过去、之后每次点击继续占着。现在悬浮窗全程不抢焦点，按钮、标签、拖动照常能点；只有在聊天框里打字时才临时借一下，打完立刻还给游戏。
  • 出装推荐一整局不变，7 分钟还在推荐初始装备。两个原因叠在一起：推荐里混进了持续树、树枝这类消耗品——它们用掉就不算「已拥有」，永远划不掉，而且开局购买率最高、稳占前排；同时同一阶段内部的排序是固定的，时钟和钱包都推不动它。现在消耗品不再进推荐栏，排序改成按「这件装备通常什么时候成型」跟着当前时间走，一路从鞋子换到大件。
  • 选了「全体」，单条快捷回复还是发到队伍。频道选择器的状态藏在聊天框内部，快捷回复看不到，只能写死发队伍。顺带修掉另一个小毛病：切到「下一件」再切回来，频道会悄悄跳回「团队」。
  • GSI 端口被别的程序占用时，会自己换一个。之前会弹窗让你去「设置 → Dota 2 → GSI 端口」改——而那个设置项根本不存在。现在自动顺延到下一个可用端口并同步改好配置文件，你只需要在提示出现时重启一次 Dota 2。
  • 补齐 202 个中文名。3 个新英雄（百戏大王、凯、朗戈）和全部 201 件中立物品之前在中文界面里显示英文名。

改进

  • 「GSI 未连接」现在会告诉你为什么。同一句话以前覆盖了七种完全不同的原因，没法自查。现在会分别指出是配置文件没装、Dota 还没启动、启动参数没生效、还是端口被别的工具占了；最常见的那种还会把配置文件的实际路径印出来——如果你装了两个 Dota，一眼就能看出配错了目录。旁边有个「复制诊断信息」，反馈问题时直接贴给我们，不用再截图。
  • 开了独占全屏会提示一句。独占全屏会绕过桌面合成，任何普通窗口都画不到游戏上面，所以悬浮窗不会显示。要盖上去只能注入游戏的图形接口，那是我们的合规红线，所以暂不支持——在 Dota 2 设置 → 视频 → 显示模式里改成「无边框窗口」即可，画质和性能几乎没差别。
  • 推荐条数变多了：悬浮窗 3 → 5 条，主界面 4 → 6 条。改了排序之后，多出来的行是「接下来该出什么」的预告，而不是继续往冷门里翻。
特别想请你帮忙验两件事：一是点悬浮窗之后游戏声音还在不在；二是打一局加速模式，看出装推荐是不是一路在变。这两条都只能在真实对局里看出来。

0.24.0-beta.0

Beta2026-09-09

出装推荐重做：加速模式下建议不再一整局不变，已经合成掉的小件也不会再赖在推荐栏里。顺带把「多少人出这件」的百分比算对了，并且现在会告诉你还差多少钱。

修复

  • 加速模式（Turbo）的出装建议会跟着打了。之前一整局几乎都停在「前期」，后期装根本推不出来——因为判断阶段只看了游戏时钟，而加速模式钱是双倍的、局却只有二十来分钟。现在按实际经济速度算，顺风局也会更早提示该出大件了。
  • 跳过小件直接买成品，小件不会再回到推荐里。比如不买回复戒直接出先锋盾，回复戒之前会重新冒出来——合成会把小件吃掉，而我们只看了背包。顺带修掉出装进度条会倒退的问题。
  • 推荐栏不再同时列出成品和它的零件。之前斧王中期会同时推荐「刃甲」和「阔剑」，而阔剑本来就是刃甲的一部分。
  • 「多少人出这件」的百分比之前是错的。斧王的跳刀显示 23%——几乎每个斧王都出的东西。现在改成相对热度：这一阶段最常出的那件是 100%，其它按比例。
  • 设置里的「允许上报崩溃报告」开关之前是不起作用的，关掉了照样上报。现在关掉立即生效（重新开启需要重启）。

改进

  • 推荐里每件装备现在显示还差多少钱、大概几分钟能攒够，买得起的会直接标出来。
  • 大件会提前提示了：以前要等到大家平均做出来的那个时间点才提醒，等于消息永远迟到；现在按你攒钱的速度提前告诉你。
  • 已经买了零件的装备会算进「还差多少」——手里有阔剑，刃甲确实比标价更近。
  • 推荐条目改用装备本身的品质配色，去掉了对玩家没意义的「本地/AI」来源标签。
这一版改动集中在实时对局里，尤其想请打加速模式的朋友帮忙看看出装建议是不是跟着局势走了。有问题欢迎到留言板说。

0.23.0-beta.3

Beta2026-09-06

紧急修一个发送 bug：连续两条提醒时，第二条可能把你剪贴板里的内容发进聊天。

修复

  • 发送靠「借用剪贴板 → 粘贴」实现，发完 0.5 秒会把你原来的剪贴板内容写回。两条提醒接连发送时，第一条的写回正好落在第二条粘贴之前，于是第二条粘贴出去的是你刚复制的东西（测试时是一个下载地址）。现在写回放进发送队列里，下一条必须等上一条彻底收尾才开始；并且只有剪贴板里还是我们写进去的短语时才写回，不会覆盖你中途新复制的内容。
如果你在用 beta.1 / beta.2 并开了自动发送：请更新到 beta.3，或在更新前先关掉自动发送。

0.23.0-beta.2

Beta2026-09-06

根据 beta.1 第一轮真机反馈修的一版：随时都能发、消息带时间、自动发送不再半路停。

新增

  • 随时发送：不再只能在提示条的 3 秒内点「喊队友」。事件列表里的每条提醒行有「发送」按钮；标题栏的倒计时胶囊点开后列出接下来 6 个节点，每个都能直接发。三处共享同一份「已发送」状态。
  • 消息带时间：发到队伍频道的话现在是「[03:00] 莲花刷了」，队友知道说的是哪一波。
  • 魔方（折磨者）首刷：20:00 提醒。被杀后 10 分钟的重生时刻靠时钟推不出来，暂不提醒。

修复

  • 开了自动发送后，第 6 条之后的提醒不再进聊天（经验符等）。原因是每局 6 条的保护上限太低，现在放宽为纯防失控的兜底，每个节点每次只发一条。
  • 提示条先显示、再后台发送；发送失败时「喊队友」按钮会回来，可以手动补发。之前提示条要等发送完才弹出，晚 1 秒左右。
  • 新一局开始后，悬浮窗事件列表会清空，不再顶着上一局的记录。

0.23.0-beta.1

Beta2026-09-06

新增关键时间提醒：莲花、符点、昼夜、10 分游走这些节点，到点前几秒悬浮窗提醒你，想喊队友点一下就行。

新增

  • 关键时间提醒：由官方 GSI 的对局时钟驱动。内置赏金符、水符、莲花、功能符、经验符、天黑、天亮、10 分游走窗口、叠野秒数 9 个节点，每个可单独开关、设置提前 5 到 60 秒。
  • 悬浮窗提示条 + 提示音：到点前从悬浮窗顶部滑出，3 秒收起；短促双音提示，可关。系统通知作为可选项（默认关，因为独占全屏时看不见）。
  • 标题栏倒计时胶囊：悬浮窗标题栏常驻「下一个节点还有多久」，30 秒内变蓝。

修复

  • 设置 → DOTA 2 分区里 cfg 绑定行下方多出一条横线。
  • 两条提醒同一秒到点（如 6:00 的莲花 + 功能符）时，发送改为排队进行，不再互相打乱按键。
  • 人机 / 房间局第二局不再漏提醒（这类对局的 matchid 都是 0，改为按时钟倒退识别新一局）。
合规说明：提醒只读对局时钟，不读敌方任何信息，不改游戏。「自动发送」是我们第一次加入"按游戏状态自动发消息"的能力，所以做成默认关闭、显式警告、每局限量。合规页会随正式版同步更新。
