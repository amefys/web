②安装并重启电脑

整个过程 2 分钟，重启是必须的，跳过会出现“设备不存在”。

1

解压 zip

下载得到 VBCABLE_Driver_Pack45.zip（版本号可能不同）。右键 → 全部解压到任意文件夹。直接在压缩包里双击运行会安装失败。

2

以管理员身份运行安装器

64 位系统（绝大多数）运行 VBCABLE_Setup_x64.exe：右键 → 以管理员身份运行。出现用户账户控制弹窗时点“是”。

VB-Audio Virtual Cable 安装器
Install Driver Uninstall Driver

点击左侧 Install Driver，等待几秒出现 “…completed successfully” 即可。

若提示 Windows 安全中心拦截：选择“仍要运行”。驱动带 VB-Audio 数字签名，可在文件属性中验证。

3

重启电脑（必须）

虚拟声卡驱动在重启后才会注册到系统。不重启 = AMEFYS 检测不到设备，这是最常见的“装了没用”原因。

③验证安装 + 设置 48kHz 音频格式

重启后 1 分钟完成。统一 48000Hz 是防爆音 / 无声 / 杂音的关键。

1

确认设备已出现

右键任务栏喇叭图标 → 声音设置 → 拉到底部 更多声音设置（Win10 为“声音控制面板”）。在“播放”与“录制”两个选项卡里应分别看到：

声音控制面板 · 播放
CABLE Input (VB-Audio Virtual Cable)就绪
扬声器 / 耳机（你原来的设备）默认设备 · 保持不动
声音控制面板 · 录制
CABLE Output (VB-Audio Virtual Cable)就绪
麦克风（你原来的设备）保持不动
⚠️
不要把 CABLE 设为系统默认设备 —— 否则整台电脑的声音都会被吞进虚拟线、耳机变哑巴。默认设备保持你原来的扬声器 / 麦克风，剩下的交给 AMEFYS 自动配置。
2

把两个 CABLE 设备统一为 16bit / 48000Hz

分别双击 CABLE Input（播放页）和 CABLE Output（录制页）→ 高级选项卡 → 默认格式选 “16 位，48000 Hz (DVD 音质)” → 确定。

CABLE Input 属性 · 高级
16 位，44100 Hz (CD 音质)
16 位，48000 Hz (DVD 音质) ✓
24 位，96000 Hz (录音棚音质)

采样率不一致是发送侧爆音 / 电流声 / 变速的头号原因。AMEFYS 一键配置时也会检测并提醒，但系统格式只能在这里手动改。

④回到 AMEFYS，一键完成剩下所有配置

驱动是唯一需要你手动做的事，其余全自动。

✓

打开 AMEFYS → 设置 → 游戏语音 → 开始一键配置（请先关闭 DOTA2）。软件将自动：

检测 CABLE Input / Output 是否就绪、采样率是否为 48kHz
定位 Steam / DOTA2 目录，写入语音按键与参数配置
设置 Windows 默认通讯录音设备
回环自检：自己发一段测试音并采回，确认全链路贯通

看到四项全部 ✓ 后进游戏即可使用：按 V 发队伍语音、按 B 发开黑小组语音。

故障排查

点开对应症状。

装完了，AMEFYS 还是检测不到 CABLE 设备
按概率排查：
  1. 没重启电脑 —— 占 90%。重启后再试。
  2. 安装时没用管理员身份运行 —— 重新右键“以管理员身份运行”装一次。
  3. 在压缩包内直接运行了安装器 —— 先解压再装。
  4. 设备被禁用 —— 声音控制面板空白处右键 → 勾选“显示禁用的设备”，若 CABLE 是灰色，右键启用。
队友说听到的声音爆音 / 有电流声 / 像快进
99% 是采样率不一致。按本页 第 ③ 步 把 CABLE Input 与 CABLE Output 都设为 16 位 / 48000 Hz，并在两个设备的“高级”选项卡里取消勾选“允许应用程序独占控制此设备”后重试。
按 V / B 没人听到声音
  1. 先在 AMEFYS 里跑一次回环自检（设置 → 游戏语音 → 一键配置），确认软件到 CABLE 的链路是通的。
  2. 自检通过仍无声：进 DOTA2 设置 → 音频，确认语音输入设备指向 CABLE Output、语音模式为按键说话（一键配置会写好，若手动改过会被覆盖）。
  3. 确认游戏内没有把自己静音，且当前处于对局中（大厅里队伍语音不生效）。
装完后电脑没声音了 / 麦克风失灵
你把 CABLE 设成系统默认设备了。右键喇叭图标 → 声音设置 → 把“输出”改回你的扬声器/耳机、“输入”改回你的物理麦克风。CABLE 不需要也不应该是默认设备（AMEFYS 仅把它设为“默认通讯设备”供游戏语音使用）。
Windows 安全中心 / 杀毒软件报警
VB-Cable 是带数字签名的正规音频驱动（右键 exe → 属性 → 数字签名可见 “VB-Audio Software”）。从官网下载的安装包可放心放行；若从其他渠道下载，请删除并重新到 vb-audio.com 获取。
如何彻底卸载
重新运行解压目录里的 VBCABLE_Setup_x64.exe（管理员身份）→ 点 Uninstall Driver → 重启电脑。卸载后 AMEFYS 的语音发送与纯净采集模式会自动不可用，字幕的简易模式不受影响。
