怎么买

三步，付款后一般 1 分钟内自动开通。下面都是软件里的真实界面。

1在软件里选时长 登录 AMEFYS，打开「设置 → 账号」。在会员卡片上点一个时长，识别码会自动复制，同时浏览器打开爱发电的购买页。 识别码是 AMF- 开头的 6 位码，每个账号固定一个。
2在爱发电付款，识别码粘贴到「留言」 爱发电会显示你选的时长和价格。付款前把识别码粘贴到「留言」里（第 1 步已经自动复制好了，直接粘贴就行），再点「去支付」，微信、支付宝都可以。 第一次用爱发电，要用手机号或微信登录一下，这是爱发电自己的账号。
3回到软件，自动开通 付款完成后回到 AMEFYS，会员卡片会显示 Pro 版和新的有效期，额度马上提升。 以后用同一个爱发电账号续费，不填识别码也能认出来。

常见问题

付款时忘了填识别码怎么办？

把爱发电订单号和你的 AMEFYS 登录邮箱发到 amefys@gmail.com，或者在留言板留言，我们会尽快帮你开通。

在哪里看我的会员到期时间和订单？

软件「设置 → 账号」里能看到会员状态；也可以在官网我的账号登录查看，包括今天的额度、购买识别码和最近的订单。账号和软件、手机版 BP 是同一个。

会自动续费吗？

不会。爱发电没有任何形式的自动扣费，到期不续就自动变回免费版。

能给朋友买吗？

可以。付款时在留言里写「送」加上朋友的识别码，时长会加到朋友的账号上，也不会影响你自己以后续费。

用自己的 API Key 还需要 Pro 吗？

不需要。用自己的 Key 翻译不占我们的额度，免费版就能用。Pro 主要是给不想自己申请 Key 的玩家。

不满意能退吗？爱发电页面写着「暂不支持退款」

首次购买 7 天内、用量不多的可以全额退，具体看退款政策。爱发电付款页上的「暂不支持退款」说的是平台没有自助退款按钮；退款由我们按退款政策处理，钱会通过支付宝转账退给你。

会影响游戏账号安全吗？

不会。AMEFYS 只读 Valve 官方的 GSI 接口，不读写游戏内存、不注入游戏、不拦截网络流量。详见合规说明。
