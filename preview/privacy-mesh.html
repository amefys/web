翻译 API 怎么处理你的数据

聊天翻译功能会把你输入的原文(中文回复或粘贴的对方消息)发给翻译引擎。 我们支持多个引擎,默认通过 AMEFYS 后端代理调用:

默认模式:走 AMEFYS 后端代理

  • 请求经 AMEFYS Supabase Edge Function 转发到目标引擎(火山 / Azure / Claude / OpenAI 等)
  • 我们的代理不存储翻译内容,只对单 IP 做速率限制
  • 引擎方的隐私政策对你适用 — 但因为是 AMEFYS 的 key,引擎方拿到的是 AMEFYS 的标识,不是你个人的

BYO Key 模式:走你自己的 API Key

  • 请求直接从你的电脑发给翻译引擎,不经过 AMEFYS 服务器
  • 引擎方拿到你的 API key — 隐私边界跟你自己直接调用该引擎一样
  • 没有速率限制,适合高频用户

哪些数据从不离开你的电脑

  • GSI 实时数据:DOTA 2 通过 POST 推送到本地 :4000/gsi,只在本进程内处理
  • 翻译缓存:本地 SQLite 表 translation_cache,从不上传
  • App 设置:本地 JSON 文件 ~/Library/.../amefys.json
  • 未登录用户的对局历史:仅本地 SQLite,从不上传

你的权利 / 操作入口

查看 / 导出你的数据

App 内 设置 → 数据与隐私 提供:

  • 导出本地对局历史为 JSON / CSV
  • 导出云端账号关联数据(如已登录)
  • 查看本地数据库文件路径 + 大小

删除你的数据

  • 本地数据:设置 → 数据与隐私 → 清空对局历史 / 清空翻译缓存
  • 云端数据:设置 → 账号 → 注销账号(删除所有 Supabase 端关联数据,48 小时内生效)
  • 完整卸载:删除 ~/Library/Application Support/amefys/ 目录即清除全部本地痕迹

关闭可选功能

  • 错误上报:设置 → 数据与隐私 → 关闭"匿名崩溃报告"
  • 云端同步:不登录 = 完全不上传
  • 翻译:不输入文字 = 不发送任何内容

数据保留期

  • 本地数据:永久保留 — 由你完全控制
  • 云端对局历史:保留到账号注销或你主动删除;不主动清理
  • 翻译 API 请求:不存储;请求转发完即丢
  • 速率限制日志:仅 IP + 时间戳,30 天后自动清除
  • Sentry 崩溃报告:Sentry 默认 30 天,我们不延长

未成年用户

AMEFYS 不主动针对未成年用户。如果你未满 16 岁,请在监护人指导下使用。 我们不会有意收集未成年用户的个人数据 — 如果你认为有这种情况发生, 请发邮件给 amefys@gmail.com,我们会立即处理。

政策变更通知

若本政策实质性修改(新增数据收集类型 / 新第三方服务等),我们会:

  • 页面顶部"生效日期"更新
  • App 内弹一次提示卡片,要求用户主动确认
  • 已登录用户:发邮件通知

纯文字 / 格式 / 错别字修订不视为实质性修改,不会触发通知。

问题 / 投诉

隐私相关问题、删除请求、数据导出 — 都发到 amefys@gmail.com。 我们会在 7 个工作日内回复。
