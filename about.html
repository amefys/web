合规白皮书

透明，且可验证。

应用代码当前处于商业开发阶段（暂未开源），但所有合规承诺可通过网络流量与文件系统行为独立验证。完整合规白皮书见 COMPLIANCE.md。

🔒 Valve 合规红线

零反作弊豁免，零灰色操作

  • ❌ 不读游戏进程内存
  • ❌ 不修改游戏文件 / 不注入 DLL
  • ❌ 不拦截游戏网络流量
  • ❌ 不显示敌方隐藏信息（雾内单位、技能 CD）
  • ✅ 仅用 Valve 官方 -gamestateintegration 接口读对局
  • ✅ 仅用游戏内置 keybind + 剪贴板发消息
📦 数据默认本地

本地优先，云同步可选

  • 本地永驻：对局数据、聊天历史、翻译缓存、应用日志（SQLite）
  • 登录后可选同步：用户偏好、自定义快捷回复包、对局元数据（Supabase + RLS）
  • 绝不上传：聊天原文、翻译结果、应用日志、API Key
  • 一键清除本地数据 / 删除账号（云端 RLS 级联）
🔑 第三方 API Key

进系统 keychain，永不入库

  • Claude / OpenAI / DeepL / 火山 / 阿里 / Gemini 的 API Key 由 safeStorage 加密后存系统 Keychain
  • 永不进入 SQLite、日志、Supabase、Sentry 或任何文件
  • 随时可在设置中查看 / 编辑 / 删除
🔍 行为可验证

不靠源码，流量也查得清

  • 用 mitmproxy / Wireshark 可独立抓包验证出站连接 —— 应看到 Supabase / Sentry / 用户配的 LLM，不应看到 Steam / Dota 2 服务器
  • 用 fs_usage / Process Monitor 监控文件读写 —— 不会触碰 Dota 2 客户端文件
  • 合规咨询 / 审计请求：GitHub Issue · 5 工作日内响应
  • 核心代码当前未开源（商业开发期），保留未来按需开放的可能
