合规说明

透明，且可验证。

AMEFYS 是非官方 DOTA 2 辅助工具，严格遵守 Valve 用户协议。这页详细说明我们做什么、不做什么、为什么不会被 VAC 封号。

最后更新：2026-05-24

简要结论

AMEFYS 只通过 Valve 官方支持的 GSI（Game State Integration）接口读取数据，不修改游戏内存、不注入 DLL、不拦截网络、不读取敌方隐藏信息。聊天发送通过游戏自带的 .cfg + alias + bind 机制 — 跟用户在 console 里手动配置完全等价。

如果你在意"装这个软件会不会被 VAC 封号" — 答案是不会。我们做的事情在 Valve 的政策允许范围内，跟你装一个 Steam Workshop 上的 HUD 修改器同等性质。

我们做什么 / 不做什么

✓

我们做的事情

  • 通过官方 GSI 接口读取你的英雄、装备、对局状态
  • 用本地规则 + AI 给出装备推荐
  • 调用翻译 API 翻译你看到的聊天内容
  • 通过 .cfg + alias + bind 帮你发送预制聊天文本
  • 在本地 SQLite 存对局历史（可导出 / 删除）
  • 登录用户的对局数据可选择同步到 Supabase 云端
✗

我们不做的事情

  • 读取 / 修改 DOTA 2 进程内存
  • 注入 DLL / dylib / 任何代码到游戏进程
  • 拦截 / 修改 / 嗅探游戏网络流量
  • 读取敌方英雄位置 / 雾内视野 / 隐身单位
  • 读取敌方背包 / 技能冷却 / 等级 / 金钱
  • 自动施法 / 自动连招 / 模拟鼠标精确点击

使用的官方接口

接口 能读什么 Valve 支持等级
Game State Integration (GSI) 己方英雄状态、装备、KDA、对局进程、地图时钟、己方金钱 / 经验 官方支持，有公开文档
cfg / alias / bind 读不到任何信息；写聊天内容到 chat box（等价于你手动 console 命令） 游戏内置脚本机制
Steam Web API （可选）登录用户的 Steam ID、DOTA 2 公开战绩 需要用户授权
OpenDota API 英雄 / 装备元数据、历史出装统计（非实时，只查历史） 第三方公益项目

跟 Valve 政策的关系

Valve 的 Steam 用户协议 第 6 节"软件使用规范"允许第三方工具，只要它们：

…不修改 Steam 客户端或任何 Subscription 软件、不获取超出 Valve 公开接口范围的游戏状态信息、不干扰其他玩家的体验、不用于商业作弊…— Steam Subscriber Agreement §6（节选）

AMEFYS 的每一项功能都在这条规则的"允许"侧 — 我们没有理由相信 Valve 会反对一个只读自己的 GSI 数据 + 通过游戏内置脚本发送预制文字的工具。

如果你对某个具体功能是否合规有疑虑，直接发邮件给我们，我们会逐条说明。

会不会被 VAC 封号？

不会。VAC（Valve Anti-Cheat）的检测目标是"修改游戏内存 / 注入代码 / 文件签名异常"。AMEFYS 不做这些事 — 它是一个独立桌面进程，跟 DOTA 2 通过 HTTP 协议（GSI）交换 JSON 数据，跟 Twitch 直播插件、SteelSeries OLED 显示工具的工作方式完全等价。

类似的 GSI 工具（Overwolf 系列、DOTA Plus 第三方插件、StreamProfile 等）已经在 DOTA 2 社区合规使用多年，没有任何 VAC 误封先例。

独立审计邀请

我们欢迎安全研究者 / DOTA 2 社区成员对 AMEFYS 进行行为审计：

  • 网络层：用 Wireshark 抓 DOTA 2 进程的全部流量 — 你会发现 AMEFYS 跟它完全无关
  • 进程层：用 Process Explorer 看 DOTA 2 句柄 — AMEFYS 不会出现在任何句柄持有者列表里
  • 文件层：看 DOTA 2 安装目录 — 我们只往 cfg/gamestate_integration_amefys.cfg 写过一个文件，其他文件从不动
  • 代码层：仓库公开后（beta 阶段后）可逐行审计
