合规与免责声明

AMEFYS 是非官方 DOTA 2 辅助工具，与 Valve / Steam 没有任何关联。DOTA 2 与 DOTA 2 Logo 是 Valve Corporation 的注册商标。

本工具仅通过游戏内置的 GSI（Game State Integration）接口读取数据，严格遵守 Valve 用户协议。不修改游戏内存、不注入 DLL、不拦截网络流量、不读取敌方隐藏信息（雾内视野等）。

完整合规姿态详见 合规说明。

数据来源

英雄数据、装备数据、对局统计和视觉资源来自以下公开 API 和 CDN。

OpenDotaFree API
英雄 / 装备元数据、出装统计、对局赔率。开源公益项目，数据由社区维护。
Steam CDNPublic CDN
英雄头像 / 装备图标。Valve 通过 cdn.cloudflare.steamstatic.com 公开提供。
DOTA 2 GSIOfficial
Valve 官方游戏状态集成接口。本工具读取的所有实时对局数据均来源于此。
DOTA 2 WikiCC-BY-SA
英雄技能说明、装备配方、合成路线参考。社区共同编辑维护。
