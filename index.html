AMEFYS 是什么？

AMEFYS 是一款免费的 DOTA 2 实时辅助工具，Windows 与 macOS 桌面端。它做三件事：把队友和对手的聊天实时翻译成你的母语，并让你一键回敬一整段翻译好的文字；根据当前对局推荐出装与关键道具时机；用快捷回复和社区语料包在悬浮窗里一键发送预制文本。所有对局数据只来自 Valve 官方的 Game State Integration（GSI）接口，不读取游戏内存、不注入代码、不拦截网络，对局记录默认只存在你自己的电脑上。永久免费，没有内购和广告。

怎么让 AMEFYS 连上 DOTA 2？

第一次打开会有 GSI 配置向导：一键把配置文件写入 DOTA 2 的 cfg/gamestate_integration/ 目录，再把 -gamestateintegration 粘贴进 Steam 的启动选项，进入游戏主菜单即自动连接，全程约 30 秒。

AMEFYS 这个名字是怎么来的？

来自 DOTA 圈一个流传已久的梗：AME + FY + Somethings。

使用 AMEFYS 会被 Valve 封号吗？

不会。AMEFYS 仅使用 Valve 官方提供的 Game State Integration 公共接口读取对局状态（启动选项需加 -gamestateintegration，Valve 2022 起的默认要求）。回发消息走 DOTA 内置聊天框热键 + 剪贴板粘贴，与玩家手动操作完全等价：不读取游戏内存、不修改客户端文件、不拦截网络流量、不发出任何官方 API 之外的指令。

正式天梯能看到敌方装备 / 队友经济 / 小地图位置吗？

不能。这是 Valve 反作弊设计的限制：正式对局中 GSI 只推送「自己英雄」相关数据。AMEFYS 不会绕过此限制，所有建议均基于你自己的状态 + 选英雄阶段已公开的双方阵容。观战 / 教程 / Demo 模式下可以拿到完整数据。

翻译能自动发送回游戏吗？

能。AMEFYS 的「快捷回复」按钮会自动完成：翻译你预设的中文短语 → 写入系统剪贴板 → 用 DOTA 默认聊天热键（Enter = 队伍 / Shift+Enter = 全频道）打开聊天框 → Ctrl+V 粘贴 → 回车发送。整个过程与玩家手动操作完全等价，单条 ~300ms 完成；批量发送间隔 100ms – 10s 可在设置中调节。

翻译是云端处理还是本地？

默认为混合模式：常见战术口令由本地小模型即时翻译；超过 8 个词的长句送云端处理。完全离线模式可在设置中开启，但会牺牲部分准确度。

支持中国大陆账号吗？

支持。完美兰国服、Steam 国际服、东南亚服均可使用。微信登录与翻译云端走国内节点，延迟 < 80ms。

对电脑配置有要求吗？

无额外要求。AMEFYS 占用资源极低（< 200MB 内存），可完美与 DOTA 2 同时运行。
