关于 AMEFYS
你想知道的。

AMEFYS 是什么？

AMEFYS 是一款免费的 DOTA 2 实时辅助工具，Windows 与 macOS 桌面端。它做三件事：把队友和对手的聊天实时翻译成你的母语，并让你一键回敬一整段翻译好的文字；根据当前对局推荐出装与关键道具时机；用快捷回复和社区语料包在悬浮窗里一键发送预制文本。所有对局数据只来自 Valve 官方的 Game State Integration（GSI）接口，不读取游戏内存、不注入代码、不拦截网络，对局记录默认只存在你自己的电脑上。跑在本机的功能免费；云端翻译与语音识别每天有免费额度，会员用于提升额度，没有广告。

怎么让 AMEFYS 连上 DOTA 2？

第一次打开会有 GSI 配置向导：一键把配置文件写入 DOTA 2 的 cfg/gamestate_integration/ 目录，再把 -gamestateintegration 粘贴进 Steam 的启动选项，进入游戏主菜单即自动连接，全程约 30 秒。

AMEFYS 这个名字是怎么来的？

来自 DOTA 圈一个流传已久的梗：AME + FY + Somethings。

手机上能用 AMEFYS 的 BP 推荐吗？

能。手机浏览器打开 amefys.com/bp，用电脑版同一个账号登录即可，不用装 App，游戏电脑上什么都不装。最快的是点「拍照识别」，对着电脑拍一张选人界面，禁用和已选会自动填进去（目前只认中文客户端）；也可以按住「我方选 / 敌方选 / 禁用」说英雄名，俗称也认，或者直接点选；推荐选和建议禁与电脑版是同一套数据，来自几百万局公开天梯对局，每天更新。

使用 AMEFYS 会被 Valve 封号吗？

不会。AMEFYS 仅使用 Valve 官方提供的 Game State Integration 公共接口读取对局状态（启动选项需加 -gamestateintegration，Valve 2022 起的默认要求）。回发消息走 DOTA 内置聊天框热键 + 剪贴板粘贴，与玩家手动操作完全等价：不读取游戏内存、不修改客户端文件、不拦截网络流量、不发出任何官方 API 之外的指令。

正式天梯能看到敌方装备 / 队友经济 / 小地图位置吗？

不能。这是 Valve 反作弊设计的限制：正式对局中 GSI 只推送「自己英雄」相关数据。AMEFYS 不会绕过此限制，所有建议均基于你自己的状态 + 选英雄阶段已公开的双方阵容。观战 / 教程 / Demo 模式下可以拿到完整数据。

翻译能自动发送回游戏吗？

能。AMEFYS 的「快捷回复」按钮会自动完成：翻译你预设的中文短语 → 写入系统剪贴板 → 用 DOTA 默认聊天热键（Enter = 队伍 / Shift+Enter = 全频道）打开聊天框 → Ctrl+V 粘贴 → 回车发送。整个过程与玩家手动操作完全等价，单条 ~300ms 完成；批量发送间隔 100ms – 10s 可在设置中调节。唯一会「不经点击」发消息的是「关键时间提醒」的到点自动发送：它默认关闭，需要你在设置里主动打开，开启时会有明确警告，开启后每个节点只发一条预制短语（如「莲花要刷了」——用将来时，因为提醒在事件发生前 8–45 秒触发）。

翻译是云端处理还是本地？

云端处理，两条路可选：默认走 AMEFYS 的翻译代理（登录即用，每天有免费额度）；也可以在设置里填自己的 API Key，客户端直连你选的厂商，不经过我们。两者都需要联网——目前没有离线翻译。已翻译过的句子会命中本地缓存，不重复计费。

屏幕识别提示语言没装，可我明明装了语言包？

这是 Windows 的设计，不是软件出了问题。Windows 把「界面显示这门语言」和「认得出这门语言的文字」当成两个独立的组件：你在「添加语言」里装的是前者，屏幕识别要用的是后者，它默认不装、要单独下载一次。

更麻烦的是两代系统路径不一样：Windows 11 在「设置 → 时间和语言 → 语言和区域 → 该语言的『⋯』→ 语言选项 → 语言功能」里能找到「光学字符识别」的下载按钮；Windows 10 那一页根本没有这一项，整个系统界面都没有安装入口。所以别在设置里找了 —— AMEFYS 设置页「识别语言」上方有「打开安装引导」，里面的「一键安装」两代系统通用，点一下、同意 Windows 的管理员授权框就行。

装识别组件要多久？为什么要管理员权限？装完系统语言列表里却看不到？

组件从 Windows Update 下载，慢的时候要好几分钟，期间别关窗口。装的是系统组件，所以必须提权 —— 点「一键安装」会弹出 Windows 自己的管理员授权框（要执行的命令就明明白白写在按钮上方，你是看清楚再授权）。如果 Windows 提示需要重启，那就重启后才生效。

装完请不要去系统的「首选语言」列表里找它 —— 那个列表记的是「你希望界面用哪种语言显示」，和装了哪些识别组件永远不同步，看不到是正常的。要确认是否装好，回 AMEFYS 的安装引导点一次检测，看「系统报告的识别语言」那一行。

公司或网吧电脑可能装不上：这类机器的更新来源被管理员改成了内部服务器，上面没有这个组件。没有管理员权限的话，还可以把该语言从「首选语言」里删掉再添加一次，识别组件有时会跟着一起回来，这一步不需要管理员。

为什么某些语言显示「Windows 不支持」或「近似代读」？

Windows 只提供 35 个语言的识别组件，越南语、泰语、乌克兰语、印尼语都不在里面（macOS 那边的系统识别能读越南语和泰语，这是两个平台的真实差异）。

对其中一部分我们做了降级：识别引擎认的是字母表而不是词汇，所以越南语用英文识别器代读（声调符号可能丢）、乌克兰语用俄语识别器代读（і ї є ґ 可能认错），读出来的文字送去翻译通常不受影响 —— 界面上会标成「近似代读」。泰语有自己的一套文字，任何其它识别器读出来都是乱码，所以标成「Windows 不支持」，我们不会拿一个错的去凑数。

支持中国大陆账号吗？
