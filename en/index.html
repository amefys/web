How it works

Four steps,
from launch to first item.

No anti-cheat exemption required. AMEFYS only reads match state through Valve's public Game State Integration interface, and only sends messages through Dota's own chat box hotkeys (Enter / Shift+Enter + clipboard paste) — every input is identical to a player's manual action. No game-process memory reads. No client-file modifications. No network interception.

01 / LAUNCH
Sign in

Email / GitHub / Google / Discord — pick one. 30 days remember-me; keys stay in the OS secure store. Supabase cloud sync is opt-in; local-first by default.

02 / CONNECT
Enable GSI

AMEFYS auto-detects your Steam install and writes the GSI config in one click. Add -gamestateintegration to Dota 2's launch options to enable push (Valve's default requirement since 2022). All data stays local.

03 / LIVE
Sync the match

Your hero's level / net worth / items / abilities push to the recommendation engine at 1 Hz. Chat events fan out to your chosen translation provider (Azure / DeepL / Claude / OpenAI / Gemini — BYO key supported). Ranked matches only expose your own POV (Valve anti-cheat limit).

04 / DECIDE
Get the call

Top pick / Top 3 / Timeline / Counter — switch freely. Every suggestion ships a confidence score. AMEFYS recommends; you decide.

FAQ

What you wanted
to know about AMEFYS.

Where does the name "AMEFYS" come from?

It's a tribute from the Dota community: AME + FY + Somethings.

Will using AMEFYS get me VAC-banned?

No. AMEFYS only uses Valve's public Game State Integration interface to read match state (the -gamestateintegration launch option is Valve's own default since 2022). Outgoing messages go through Dota's native chat-box hotkeys + clipboard paste, which is identical to any input you'd produce by hand: no game-memory reads, no client-file edits, no network interception, no API calls outside the official ones.

Can it see enemy items / teammate net worth / minimap positions in ranked?

No. That's Valve's anti-cheat boundary: in ranked matches, GSI only pushes data about your own hero. AMEFYS doesn't try to bypass that — every suggestion is based on your state plus the public draft. In Spectator / Demo / Tutorial modes you get the full state.

Can it auto-send the translated reply back into chat?

Yes. The quick-reply button runs the full chain: translate your preset phrase → write the system clipboard → open Dota's chat box with the native hotkey (Enter = team / Shift+Enter = all chat) → Ctrl+V to paste → Enter to send. Each message is identical to a human keystroke and takes ~300 ms. Batch interval is configurable from 100 ms to 10 s.

Is translation done in the cloud or locally?

Hybrid by default: tactical callouts hit a local model and return instantly; longer sentences go to your chosen cloud provider. Full offline mode is in Settings if you prefer — accuracy on long sentences drops a bit, but everything stays on device.

Which Dota 2 regions are supported?

All of them. AMEFYS works in EU West / EU East / US East / US West / SEA / SA / Russia / Perfect World China — anywhere Dota 2 launches. BYO translation key (Azure / DeepL / Claude / OpenAI / Gemini) means you can route through whichever provider has good latency in your region.

System requirements?

Nothing fancy. AMEFYS sits well under 200 MB of memory and ~1% CPU during a match — runs side-by-side with Dota 2 with zero impact on FPS.
