Where the money goes

AMEFYS is a solo project — no company, no investors. These are the bills that arrive every month.

CostWhat it pays for
Translation API Live two-way chat translation (EN / ZH / RU / VI / ID / FIL), billed per character — the more players, the bigger the bill
Speech recognition Cloud ASR behind voice input and voice translation, billed per second of audio
CDN and servers Installer downloads, skin delivery, and hosting for the guestbook
Domain and certificates Renewals for amefys.com and its subdomains
Development time Whatever is left is the reason new features, bug fixes and DOTA 2 patch updates keep coming
