About AMEFYS

Trash-talk 1v9. Anywhere on Earth.

Hey Dota lifers,

If you've been queueing for Dota 2 long enough that Na'Vi's fountain hook still gives you chills, that Alliance's TI3 rat doto made you laugh and cry, that OG's back-to-back TI8/TI9 underdog run is the single greatest sports story you've ever watched — you and we are on the same page.

You also know the other side of that fairy tale. You queue into EU East at 2 AM, and three of your teammates start spamming Cyrillic before the horn even sounds. You queue into US East and the Peruvians from SA bridging up the ping flame in Spanish from minute one. You queue into SEA and read "ez mid feeder" in Bahasa Indonesia, in Vietnamese, in Tagalog. You can hear the tone, you can't read the words, and you can't fire back in their language. So you mute and lose.

We thought about Dota Plus. It's built by Valve, it's good at item suggestions, and it costs real money every month. Then you check the official ranked translation toggle and… there isn't one. Dota Plus is a paywall in front of features that everyone deserves.

So we built AMEFYS. Every paid feature of the official coach — item picks, timing windows, hero counters, post-match takeaways — completely free, forever. Real-time chat translation in 9 languages — type English, hit one button, your reply lands in the Russian guy's chat in Cyrillic before he's done flaming. A UI that shifts mood with your side: emerald daylight when you draw Radiant, lavender moonlight when you load into Dire. The assistant always feels like your team.

Dota 2 is the deepest game on the planet. It's also 15 years old. The community is content-creator-rich — BSJ doing Crusader-to-Immortal hero spotlights, Purge with the unmatched essay-length analyses, Wagamama drafting fundamentals from the Riki era. Their craft is why we have a community at all in 2026.

AMEFYS is our love letter back to that community: a free coach for every pub player. Hindi-speaking solo carry in Mumbai, Quechua-speaking pos 4 in Lima, Turkish stack at 4 AM, Filipino esports house grinding ranked at Cebu — all on the same footing, finally.

We're a tiny team and AMEFYS will only get better through the people using it. Every GitHub issue you file, every Discord message you post, every "hey can you add X" email — gets read. That's the only reason this exists.

And whatever side of the map fate gives you next match — radiant top lane, dire safe lane, mid against a five-time Top 10 immortal in your shotcalling channel: trash-talk 1v9, anywhere on Earth.

— AMEFYS, with love from a Dota pub somewhere

Compliance white paper

Transparent & verifiable.

The application code is under active commercial development (not currently public), but every compliance claim is verifiable via network traffic and filesystem behaviour. Full white paper at COMPLIANCE.md.

🔒 Valve red lines

Zero anti-cheat exemption, zero grey-area work

  • ❌ No game memory reads
  • ❌ No file mods / DLL injection
  • ❌ No network interception
  • ❌ Never reveal hidden-vision info (fogged units, cooldowns)
  • ✅ Read match state ONLY via Valve's -gamestateintegration
  • ✅ Send chat ONLY via the game's keybind + clipboard paste
📦 Local-first data

Local-first, cloud sync opt-in

  • Local SQLite (always): match data, chat history, translation cache, app logs
  • Cloud opt-in: settings, custom quick-reply packs, match metadata (Supabase + RLS)
  • Never uploaded: chat originals, translation outputs, app logs, API keys
  • One-click wipe local data / delete account (cloud RLS cascade)
🔑 Third-party API keys

In your OS keychain, never in our DB

  • Claude / OpenAI / DeepL / Volcano / Aliyun / Gemini API keys are encrypted via safeStorage and stored in your OS keychain
  • Never enter SQLite, logs, Supabase, Sentry, or any file
  • View / edit / delete anytime in Settings
🔍 Behaviour-verifiable

No source needed — traffic tells the story

  • Run mitmproxy / Wireshark and verify outbound connections — Supabase / Sentry / your chosen LLM; never Steam / Dota 2 servers
  • Use fs_usage / Process Monitor to verify file I/O — Dota 2 client files are never touched
  • Audit requests & compliance questions: GitHub Issue · 5 business days response
  • Application source is currently closed (commercial dev stage); we reserve the option to open it in the future
